## Responsibilities

- Core UE5/C++ systems architecture for the petting experience and mini-games
- Touch-driven petting system: IK-based paw and body interaction, morph-target reactions, softmax socket blending
- Data-driven emotional state and micro-reaction system built on reusable data assets
- Nose Basket mini-game: slingshot input, projectile physics, target and scoring systems, dedicated level architecture
- Mobile rendering optimization and touch/pointer input systems for iOS
- Owned the full iOS build pipeline, including Windows-to-Mac remote builds and Git/LFS setup
